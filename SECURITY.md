# Security policy

Acrium is a hosted MCP server at https://acriumautomated.com/mcp. This repository holds its public listing metadata.

## Reporting a vulnerability

Please email **malin.ethyn@acriumautomated.com** with "Security" in the subject. Include what you found, how to reproduce it, and what it could affect. Please don't open a public issue for security problems.

We'll acknowledge reports within 3 business days and keep you updated until it's fixed. We won't take legal action against good-faith research that avoids privacy violations, data destruction and service disruption, and that gives us reasonable time to fix the problem before you disclose it.

## Scope

- The MCP server and its OAuth endpoints on acriumautomated.com
- The Acrium dashboard and API on acriumautomated.com

Third-party platforms Acrium connects to (Shopify, Google Ads, social networks) have their own security programs. Please report issues in those platforms to them.
